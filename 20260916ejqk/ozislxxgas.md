无锡市妇幼保健院“妇幼青志荟”志愿服务项目立足专业优势，以为妇女、青少年、婴幼儿提供全生命周期的关怀为宗旨，致力于通过“**线上+线下**”“**传播+互动**”“**走出去+请进来**”的志愿服务模式，推动青春志愿公益服务不断拓展、聚焦为民。项目由医院团委牵头成立，项目负责人和主要成员均为医院团干部和青年党团员。

**奉献青春，****十三年****做好一件事**

  //  

“妇幼青志荟”志愿服务项目最早发端于2009年建立的**“Baby-Class亲子课堂”公益讲**，至今已有**13年**的运作经验。早在2009年，项目团队就“走街串巷”，免费为无锡市各街道社区1岁以内婴儿家庭提供早教课程，同时团队还积极参与社会救助和社会服务。如**“妇幼天使在行动”**：开展社区义诊、开设知识讲座、免费为贫困女工健康体检；**“让我为你做件事”**：组织农民工子女参观无锡博物院、志愿者们在儿童节走进福利中心慰问并捐助孤幼；**“两代人携手共进”**：团支部结对帮扶孤老职工，青年文明号集体帮扶卫校困难学生等。

  //  

2016年，项目团队在志愿服务的基础上总结经验，探索品牌化路线；2019年，开设专门面对青少年的课程，探索形成“妇幼青志荟”志愿服务项目。不断打磨至今，项目已开展线下服务**500余场**、线上服务**80余次**。项目和主讲人多次获得各类省、市级荣誉。

**立足专业，****四大课堂****聚焦全生命周期**

  //  

经过调研，“科学育儿”需求的爆发式增长既令项目团队欣喜万分，又让项目团队焦虑不已。欣喜的是，专业优势有了“用武之地”；焦虑的是，市场上早教机构水平层次不齐且收费高昂。在医院党委行政的大力支持下，“不知足”的项目团队开始思考如何服务更多人群，并自此开启项目化、品牌化建设进程。

  //  

围绕“为妇女儿童提供全生命周期的关怀”这一理念，团队设立**“Baby-Class亲子课堂”“Super-Star青享课堂”“Mommy-Class宝妈课堂”**以及**“Lonely-Star拾梦课堂”**四大课堂。分别针对0-3岁以内婴幼儿、青少年、孕产妇以及孤独症患儿，提供儿童早教、青春期、母乳喂养等知识科普，2022年项目开展了第一场针对孤独症患儿的“Lonely-Class拾梦课堂”公益讲。项目除了“走出去”的科普讲座和义诊服务，还设有“请进来”的岗位体验和主题活动，通过“沉浸式”体验方式加深活动的参与度和实效性。

**多维发力，受益人次****突破百万**

  //  

2020年新冠肺炎疫情爆发，项目发展一度受到了很大的阻滞。项目团队结合互联网医院建设思路，开设了抖音和微信平台，开展线上志愿服务——**“妇幼青志荟”科普云课堂**。每次用1分钟甚至更短的时间讲解清楚一个问题，为受到疫情困扰或是出行不便的妇女儿童提供“贴身”服务。同时，项目设置“有求必应”机制，根据妇女儿童提出的切身需求制定科普主题，弥补线上服务“互动感不足”的缺憾。线上志愿服务的开展突破了时间空间的限制，把“妇幼青志荟”的服务对象从无锡市扩展到了全国。

  //  

自开设线上服务以来，已发布科普云课堂**78期**，累计点击量突破**173万人次**。项目还积极搭建服务平台，与无锡卫生高等职业技术学校达成共建协议，3名专家受聘为青春期“同伴教育”队伍导师，通过以点带面的方式辐射更多青年，进一步加强项目的影响力。
